# 작업 일지 (HANDOFF)

Codex와 Claude Code가 번갈아 이 프로젝트를 고칩니다. **작업을 시작하는 도구는 이 파일부터 읽고, 작업을 마치는 도구는 맨 위에 기록을 하나 더합니다.**
그러면 다음 도구가 무엇이 끝났고 무엇이 남았는지 바로 알 수 있습니다. 선생님도 이 파일로 진행 상황을 볼 수 있습니다.

## 쓰는 법 (에이전트용)
- **새 기록은 "기록" 제목 바로 아래(맨 위)에** 더합니다. 예전 기록은 고치지 않습니다(틀린 것이 있으면 새 기록에서 바로잡습니다).
- 틀은 아래 그대로, 짧고 사실대로 적습니다. 선생님이 읽을 수 있게 한국어로 씁니다.
- **확인한 것과 확인하지 못한 것을 나눠** 적습니다. 가짜 응답으로만 시험한 것은 "실제로는 확인 못 함"에 적습니다.
- "다음 할 일"은 다음 도구가 바로 집어 들 수 있게 구체적으로 적고, 끝낸 항목은 다음 기록에서 빼거나 "끝남"으로 옮깁니다.
- 기록을 더한 커밋을 올린 뒤 작업을 마칩니다.

```
### YYYY-MM-DD · 도구(Codex / Claude Code) · 브랜치
**한 일**
- …
**확인한 것** (npm run check / npm test 결과, 화면 확인 등)
- …
**확인하지 못한 것 · 알려진 문제**
- …
**다음 할 일**
- …
```
