수달쌤 채널에서 가져온 제작 방식

공개 영상 10편의 대표 장면에서 확인한 구성을 반영했습니다. 왼쪽의 큰 사진·유물·지도·인용문, 오른쪽 강사, 아래 설명 문구를 배치합니다. 영상 전체를 자동 분석한 기능은 아닙니다.

  • 실물·유물 사진은 출처와 이용 조건을 기록합니다.
  • 설명할 부분을 원·밑줄·화살표로 강조하거나 확대합니다.
  • 주제가 바뀔 때 검은 배경의 제목 카드를 사용할 수 있습니다.

먼저, 완성한 대본을 넣어 주세요.

대본을 구간별로 나누고 어떤 자료가 필요한지 제안합니다. 목록을 직접 검토하고 확정한 뒤 제작을 시작합니다.

구간을 누르면 바로 이동합니다. 검색·보기 조건은 저장할 구간을 바꾸지 않습니다. 저장 대상은 ‘묶음·PPT에 포함’으로 정하세요. 출처와 파일 상태는 직접 확인해 주세요.

소스 넣기

교과서 본문, 사료 번역문, 논문 요약, 내 강의 메모 등을 붙여 넣으세요. 텍스트 파일(.txt, .md)은 글로 들어가고, PDF와 사진(교과서·사료 쪽을 찍은 사진)은 첨부로 들어가 AI 모드에서 Claude가 직접 읽습니다.

참고 영상 (유튜브)

유튜브 영상 아래 …더보기 → 스크립트 표시를 눌러 나온 자막을 복사해 붙여 넣으세요. 시각 표시와 [음악] 같은 표시는 저절로 지워집니다. 사실 자료로 고르면 내용을 참고하되 문장은 새로 쓰고, 구성·말투만 고르면 전개 방식만 본뜹니다. 참고한 영상은 업로드 설명란에 출처로 붙습니다.

한 번에 만들기 고른 것을 차례로 만듭니다. 도중에 멈춰도 만든 것은 남습니다.

설정에서 Anthropic API 키를 넣으면 Claude가 대본·판서·지도까지 한 번에 짜 줍니다. 키가 없으면 소스 문장을 장면으로 나누는 간이 방식으로 만듭니다.

대본

장면마다 내레이션, 화면(삽화) 설명, 이미지 생성용 프롬프트를 고칠 수 있습니다. 고친 내용은 자동 저장됩니다.

내레이션에서 나눌 곳을 누른 뒤 커서에서 나누기를 누르세요. 다음 장면과 합치기로 연결하거나, ↕ 끌기 손잡이와 ↑↓ 단추로 순서를 바꿉니다. 편집 전 상태는 설정 → 되돌리기 기록에 남습니다.

이미지 기획

장면마다 보여 줄 그림(샷)을 1~3장 정하고, 내레이션 문장에 맞춰 바뀌게 합니다. 모든 그림이 같은 화풍·같은 인물 모습이 되도록 프롬프트에 자동으로 넣습니다. 지명이 나오는 곳은 그림 지도 샷으로 정확한 지도를 보여 줍니다.

그림 만들기

주문서(ZIP)를 풀고 그 폴더에서 Codex를 실행해 안내문을 붙여 넣으면, 파일 이름대로 그림이 저장됩니다. 그 그림들을 ③으로 한꺼번에 불러오면 샷에 자동으로 붙습니다. ChatGPT 앱이면 샷마다 "프롬프트 복사" → 그림 받기 → "파일 넣기"로 해도 됩니다.

설정

Claude API

키는 이 브라우저(localStorage)에만 저장되며 프로젝트 백업 파일에는 들어가지 않습니다. 요청은 브라우저에서 Anthropic으로 바로 갑니다.

AI 이미지 (선택) 사진·그림풍 장면 그림을 만들 때 씁니다. Claude는 이미지를 만들지 않아서 다른 회사의 키가 필요합니다.

키는 이 브라우저에만 저장되고 백업에는 들어가지 않습니다. OpenAI 키는 platform.openai.com, Gemini 키는 aistudio.google.com 에서 만듭니다. 비용은 그림 한 장에 대략 50~100원(서비스·품질에 따라 다름)입니다.

되돌리기 기록

대본을 새로 만들거나 AI로 고치기·그리기, 백업 불러오기, 새 프로젝트 전에 그때 상태를 자동으로 남깁니다 (최근 10개).

프로젝트 영상마다 프로젝트를 하나씩 만드세요. 오른쪽 위 목록에서 바꿔 가며 작업할 수 있습니다.
