AI 꺼짐

소스 넣기

교과서 본문, 사료 번역문, 논문 요약, 내 강의 메모 등을 붙여 넣으세요. 텍스트 파일(.txt, .md)은 글로 들어가고, PDF와 사진(교과서·사료 쪽을 찍은 사진)은 첨부로 들어가 AI 모드에서 Claude가 직접 읽습니다.

참고 영상 (유튜브)

유튜브 영상 아래 …더보기 → 스크립트 표시를 눌러 나온 자막을 복사해 붙여 넣으세요. 시각 표시와 [음악] 같은 표시는 저절로 지워집니다. 사실 자료로 고르면 내용을 참고하되 문장은 새로 쓰고, 구성·말투만 고르면 전개 방식만 본뜹니다. 참고한 영상은 업로드 설명란에 출처로 붙습니다.

한 번에 만들기 고른 것을 차례로 만듭니다. 도중에 멈춰도 만든 것은 남습니다.

설정에서 Anthropic API 키를 넣으면 Claude가 대본·판서·지도까지 한 번에 짜 줍니다. 키가 없으면 소스 문장을 장면으로 나누는 간이 방식으로 만듭니다.

대본

장면마다 내레이션, 화면(삽화) 설명, 이미지 생성용 프롬프트를 고칠 수 있습니다. 고친 내용은 자동 저장됩니다.

삽화 영상

장면마다 그림을 넣으면 천천히 확대·이동(켄 번스 효과)하며 자막이 흐르는 영상이 됩니다. 그림이 없는 장면은 분위기에 맞는 배경을 그려 넣습니다.

배경음악

저작권 걱정 없는 음악(예: 유튜브 스튜디오의 오디오 보관함)을 받아 넣으세요. 내레이션이 나올 때는 자동으로 소리를 줄입니다.

없음
내 캐릭터

⑦ 손그림 탭에서 "영상 캐릭터로 저장"하거나 그림 파일을 넣으세요. 종이 바탕은 저절로 지워집니다. 장면마다 등장시킬 수 있습니다.

장면별 그림과 움직임

그림은 AI로 그리기(Claude가 세 겹 그림을 그려 시차로 움직임)를 누르거나, 직접 만든 그림 파일을 넣으세요. 목소리를 녹음하거나 음성 파일을 넣으면 영상 길이가 목소리에 맞춰지고 녹화 영상에 소리가 함께 들어갑니다.

스토리 PPT

장면마다 한 장. 삽화와 핵심 문장을 싣고, 내레이션은 발표자 노트로 들어갑니다. 지도가 있으면 지도 슬라이드도 함께 넣습니다.

지도

대본에 나온 지명을 찾아 찍었습니다. 지명·좌표·경로를 고치고, 이미지로 받거나 경로가 그려지는 영상으로 녹화하세요.

영역 (판도·점령지)

"영역 그리기"를 누르고 지도 위를 차례로 눌러 둘레를 찍은 뒤 "완성"을 누르세요.

지명
이름경도위도종류

경로: 한 줄에 하나씩 출발 > 도착 : 설명 (예: 부산 > 한양 : 일본군 북상)

판서 PPT

칠판에 분필로 쓴 듯한 요약 슬라이드입니다. 줄 앞에 -를 쓰면 들여쓰기, *는 노란 분필, !는 분홍 분필, [ ]로 감싸면 네모 칸이 됩니다.

손그림 → 판서 탭에서 변환한 그림은 이 장의 오른쪽에 붙습니다.

손그림 → 판서

종이에 그린 캐릭터를 사진으로 찍어 넣거나 여기서 바로 그리면, 칠판에 분필로 그린 그림으로 바꿔 줍니다.

원본
마우스·펜으로 직접 그려도 됩니다.

업로드 준비

유튜브에 올릴 때 필요한 자막 파일, 챕터, 제목·설명·태그, 썸네일을 만듭니다.

자막과 챕터

자막 파일(.srt)은 유튜브 스튜디오 → 자막 → 파일 업로드로 올리면 됩니다. 영상 속 자막과 같은 시각으로 맞춰져 있습니다.

수업 자료

영상으로 수업할 때 쓸 학습지(학습 목표, 빈칸 요약, 확인 문제, 모둠 활동, 토론 질문)와 퀴즈 PPT를 만듭니다.

학습지는 HTML 파일입니다. 브라우저로 열어 인쇄(Ctrl+P)하거나 PDF로 저장하세요. 퀴즈 PPT는 문제 다음 장에 정답과 해설이 나옵니다.

설정

Claude API

키는 이 브라우저(localStorage)에만 저장되며 프로젝트 백업 파일에는 들어가지 않습니다. 요청은 브라우저에서 Anthropic으로 바로 갑니다.

되돌리기 기록

대본을 새로 만들거나 AI로 고치기·그리기, 백업 불러오기, 새 프로젝트 전에 그때 상태를 자동으로 남깁니다 (최근 10개).

프로젝트 영상마다 프로젝트를 하나씩 만드세요. 오른쪽 위 목록에서 바꿔 가며 작업할 수 있습니다.
